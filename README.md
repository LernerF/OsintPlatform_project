## Описание

Aerial Sentinel — это платформа разведки по открытым источникам (OSINT), которая мониторит Telegram-каналы и чаты в режиме реального времени для обнаружения и геолокации сообщений о безопасности. Система автоматически обрабатывает сообщения через AI-классификацию, извлекает данные о местоположении и отображает инциденты на интерактивной карте в течение секунд после обнаружения.

### Возможности

| Функция | Описание |
|---------|----------|
| Мониторинг в реальном времени | События появляются на карте в течение 2 секунд после обнаружения |
| AI-классификация | Интеграция с OpenRouter для интеллектуального анализа сообщений |
| Множественные источники | Мониторинг до 500+ Telegram-источников одновременно |
| Адаптивный polling | Умный мониторинг веток комментариев на основе активности |
| Кластеризация событий | Автоматическая группировка связанных инцидентов |
| Интерактивный дашборд | Карта в реальном времени, лента событий, управление источниками |
| Человек в цикле | Встроенная очередь ревью для неточных локаций |
| Webhook-интеграция | Мгновенная доставка событий во внешние системы |

## Быстрый старт

### Требования

- Docker и Docker Compose
- (Опционально) API-ключи Telegram с [my.telegram.org](https://my.telegram.org)
- (Опционально) API-ключ OpenRouter с [openrouter.ai](https://openrouter.ai)

### Запуск через Docker

```bash
# Клонирование репозитория
git clone https://github.com/LernerF/OsintPlatform_project.git
cd OsintPlatform_project

# Создание файла конфигурации
cp .env.example .env

# Запуск сервисов
docker compose up --build

# Доступ к приложению
# Фронтенд: http://localhost:5173
# API бэкенда: http://localhost:8000/api
# Проверка здоровья: http://localhost:8000/api/health
```

Приложение запускается сразу с локальной эвристической классификацией. Для продакшена настройте учётные данные Telegram и API-ключ OpenRouter в `.env`.

### Локальная разработка

**Бэкенд:**
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

**Фронтенд:**
```bash
cd frontend
npm install
npm run dev
```

## Технологический стек

### Бэкенд
- **Python 3.11+** — основной язык
- **FastAPI** — асинхронный веб-фреймворк
- **SQLAlchemy** — ORM для работы с базой данных
- **Telethon** — клиентская библиотека Telegram
- **Pydantic** — валидация данных

- **React 18** — UI-фреймворк
- **TypeScript** — типизированный JavaScript
- **Vite** — инструмент сборки и dev-сервер
- **Leaflet** — интерактивные карты
- **Lucide React** — библиотека иконок

### Инфраструктура
- **SQLite** — встраиваемая БД (режим WAL)
- **Docker Compose** — оркестрация контейнеров

### Внешние сервисы
- **OpenRouter API** — доступ к LLM (Claude, GPT и др.)
- **Yandex Geocoder** — основное геокодирование для России
- **Nominatim** — резервное геокодирование (OpenStreetMap)

## Конфигурация

### Переменные окружения

Создайте файл `.env` из шаблона:

```bash
cp .env.example .env
```

**Основные настройки:**

| Переменная | Описание | Обязательно |
|------------|----------|-------------|
| `TELEGRAM_API_ID` | ID API Telegram | Для реальных данных |
| `TELEGRAM_API_HASH` | Хэш API Telegram | Для реальных данных |
| `TELEGRAM_SESSION_NAME` | Путь к файлу сессии | Для реальных данных |
| `OPENROUTER_API_KEY` | API-ключ OpenRouter | Рекомендуется |
| `GEOCODER_PROVIDER` | `yandex` или `nominatim` | Нет |
| `YANDEX_GEOCODER_API_KEY` | API-ключ Яндекс | Для Яндекс |
| `WEBHOOK_URLS` | URL через запятую | Нет |

Полный список опций см. в `.env.example`.

## Использование

### Добавление источников

1. **Через UI**: Нажмите `+` в панели источников, выберите из диалогов Telegram
2. **Массовый импорт**: Загрузите текстовый файл с именами каналов во вкладке "Система"
3. **Через API**: Используйте эндпоинт `/telegram/connect`

### Поток обработки событий

```
Сообщение Telegram → Фильтр по ключевым словам → AI-классификация → Извлечение локации → Геокодирование → Создание события → Доставка в реальном времени
```

### Уровни точности локации

| Уровень | Описание |
|---------|----------|
| `city` | Город из конфигурации источника |
| `district` | Район или округ |
| `settlement` | Посёлок или деревня |
| `street` | Название улицы |
| `address` | Точный адрес |
| `landmark` | Ориентир (парк, ТЦ и т.д.) |

### Важные принципы

⚠️ Эта система предназначена **только для мониторинга гражданской безопасности**.

- Все данные получены из публично доступных источников Telegram
- События включают оценки уверенности и уровни точности локации
- Система **не** предоставляет военных рекомендаций или информации для целеуказания
- Пользователи несут ответственность за соблюдение местных законов и регуляций

### Ответственное использование

- Мониторьте только источники, к которым имеете легитимный доступ
- Уважайте приватность и регламенты защиты данных
