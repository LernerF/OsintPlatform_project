# Справочник API

Полная документация REST и WebSocket API для Aerial Sentinel.

---

## Базовый URL

```
http://localhost:8000/api
```

---

## Аутентификация

В настоящее время API не требует аутентификации для локальной разработки. Для продакшен-развёртываний аутентификация обрабатывается на уровне Nginx-шлюза с использованием HTTP Basic Auth.

---

## REST-эндпоинты

### Проверка здоровья

```
GET /health
```

Возвращает статус здоровья сервера.

**Ответ:**
```json
{
  "status": "healthy",
  "version": "1.0.0"
}
```

---

### Источники

#### Список источников

```
GET /sources
```

Возвращает все настроенные Telegram-источники.

**Ответ:**
```json
[
  {
    "id": 1,
    "telegram_id": "-1001234567890",
    "title": "Пример канала",
    "username": "example_channel",
    "type": "channel",
    "city": "Москва",
    "region": "Москва",
    "enabled": true,
    "event_count": 15,
    "processed_count": 234,
    "created_at": "2024-01-15T10:00:00Z"
  }
]
```

#### Создать источник

```
POST /sources
```

Создать запись источника вручную.

**Тело запроса:**
```json
{
  "telegram_id": "-1001234567890",
  "title": "Пример канала",
  "type": "channel",
  "city": "Москва",
  "region": "Москва"
}
```

**Ответ:** Возвращает созданный объект источника.

#### Обновить источник

```
PATCH /sources/{id}
```

Обновить свойства источника.

**Тело запроса:**
```json
{
  "enabled": false,
  "city": "Санкт-Петербург"
}
```

**Ответ:** Возвращает обновлённый объект источника.

#### Список групп источников

```
GET /sources/groups
```

Возвращает сгруппированные пары источников (канал + связанный чат).

**Ответ:**
```json
[
  {
    "id": 1,
    "title": "Пример группы",
    "city": "Москва",
    "enabled": true,
    "channel_source_id": 1,
    "chat_source_id": 2,
    "event_count": 25
  }
]
```

#### Обновить группу источников

```
PATCH /sources/groups/{id}
```

Обновить свойства группы источников.

### События

#### Список событий

```
GET /events?limit=200
```

Возвращает недавние обнаруженные события.

**Параметры запроса:**
- `limit` (опционально): Максимальное количество событий (по умолчанию: 200)

**Ответ:**
```json
[
  {
    "id": 1,
    "event_type": "possible_drone_sighting",
    "confidence": 0.86,
    "risk_level": "medium",
    "summary": "Пользователь сообщает о звуке дрона",
    "text": "Слышно жужжание в районе",
    "city": "Москва",
    "district": "Центральный район",
    "lat": 55.7558,
    "lon": 37.6173,
    "precision": "district",
    "formatted_address": "Центральный район, Москва",
    "source": {
      "id": 1,
      "title": "Пример канала",
      "telegram_id": "-1001234567890"
    },
    "cluster_id": 5,
    "created_at": "2024-01-15T12:30:00Z"
  }
]
```

#### Детали события

```
GET /events/{id}
```

Возвращает детальную информацию о конкретном событии.

### Кластеры

#### Список активных кластеров

```
GET /clusters/active?limit=200
```

Возвращает текущие активные кластеры событий.

**Ответ:**
```json
[
  {
    "id": 5,
    "event_count": 3,
    "first_seen_at": "2024-01-15T12:00:00Z",
    "last_seen_at": "2024-01-15T12:30:00Z",

    "centroid_lon": 37.6173

```

#### События кластера

```
GET /clusters/{id}/events?limit=200
```

Возвращает все события, принадлежащие кластеру.

### Telegram

#### Список доступных диалогов

```
GET /telegram/dialogs?limit=200&query=search
```

Возвращает Telegram-диалоги, доступные авторизованному аккаунту.

**Параметры запроса:**
- `limit` (опционально): Максимальное количество результатов (по умолчанию: 200)
- `query` (опционально): Фильтр поиска

**Ответ:**
```json
[
  {
    "telegram_id": "-1001234567890",
    "title": "Пример канала",
    "username": "example_channel",
    "type": "channel",
    "is_connected": false,
    "paired_chat_telegram_id": null,
    "paired_chat_title": null
  }
]
```

#### Подключить диалог

```
POST /telegram/connect
```

Подключить Telegram-диалог как источник мониторинга.

**Тело запроса:**
```json
{
  "telegram_id": "-1001234567890",
  "title": "Пример канала",
  "username": "example_channel",
  "type": "channel",
  "city": "Москва",
  "region": "Москва",
  "paired_chat_telegram_id": "-1009876543210",
  "paired_chat_title": "Обсуждение"
}
```

**Ответ:** Возвращает созданный(е) источник(и).

#### Массовое подключение

```
POST /telegram/bulk-connect
```

Подключить несколько каналов из списка.

**Тело запроса:**
```json
{
  "channels": ["@channel1", "@channel2", "https://t.me/channel3"],
  "city": "Москва",
  "region": "Москва"
}
```

**Ответ:**
```json
{
  "connected": 2,
  "updated": 1,
  "failed": 0,
  "items": [
    {
      "channel": "@channel1",
      "status": "connected",
      "source_id": 1
    }
  ]
}
```

### Ревью локаций

#### Список ожидающих ревью

```
GET /location-reviews?status=pending&limit=200
```

Возвращает события, требующие ручной верификации локации.

**Параметры запроса:**
- `status` (опционально): Фильтр по статусу (pending, resolved, rejected)
- `limit` (опционально): Максимальное количество результатов

**Ответ:**
```json
[
  {
    "id": 1,
    "event_id": 15,
    "event_text": "Слышно что-то рядом с парком",
    "extracted_location": "парк",
    "city": "Москва",
    "created_at": "2024-01-15T12:00:00Z"
  }
]
```

#### Разрешить ревью

```
POST /location-reviews/{id}/resolve
```

Установить локацию для события вручную.

**Тело запроса:**
```json
{
  "lat": 55.7558,
  "lon": 37.6173,
  "formatted_address": "Парк Горького, Москва",
  "precision": "landmark",
  "operator_comment": "Подтверждено как Парк Горького"
}
```

**Ответ:** Возвращает обновлённое событие.

#### Отклонить ревью

```
POST /location-reviews/{id}/reject
```

Пометить событие как имеющее неразрешимую локацию.

**Тело запроса:**
```json
{
  "operator_comment": "Локация слишком размыта"
}
```

**Ответ:** Возвращает обновлённое событие.

### Геокодирование

#### Подсказки локаций

```
GET /geo/suggestions?kind=city&query=mos®ion=Region
```

Возвращает автозаполнение для ввода локации.

**Параметры запроса:**
- `kind` (обязательно): Тип локации ("city" или "region")
- `query` (обязательно): Поисковый запрос
- `region` (опционально): Контекст региона для поиска города

**Ответ:**
```json
[
  {
    "name": "Москва",
    "region": "Москва",
    "country": "Россия"
  }
]
```

## Ответы об ошибках

Все эндпоинты возвращают консистентный формат ошибки:

```json
{
  "detail": "Описание ошибки"
}
```

### HTTP-коды статусов

| Код | Описание |
|-----|----------|
| 200 | Успешно |
| 201 | Создано |
| 400 | Неверный запрос — Некорректный ввод |
| 404 | Не найдено |
| 422 | Необрабатываемая сущность — Ошибка валидации |
| 500 | Внутренняя ошибка сервера |

---

## Ограничения запросов

API не реализует ограничение запросов на уровне приложения. Однако базовые сервисы имеют свои лимиты:

- **Nominatim**: 1 запрос в секунду
- **Яндекс Геокодер**: Согласно вашему тарифу
- **OpenRouter**: Согласно вашему тарифу
- **Telegram API**: Подвержен FloodWait

---

## Идемпотентность

Доставки webhook включают заголовок `Idempotency-Key: event-{id}`. Принимающие системы должны использовать этот ключ для предотвращения дублирования обработки событий.

---

## CORS

CORS включён для источников, указанных в переменной окружения `CORS_ORIGINS` (через запятую). По умолчанию: `http://localhost:5173`
