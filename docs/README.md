# Aerial Sentinel

**Платформа OSINT мониторинга в реальном времени для гражданской безопасности**

---

## Обзор

Aerial Sentinel — это микросервисная платформа, которая мониторит Telegram-каналы и чаты в реальном времени, автоматически обнаруживает и геолокирует сообщения о безопасности, связанные с воздушной активностью. Система обрабатывает сообщения через AI-классификацию, извлекает данные о местоположении и отображает инциденты на интерактивной карте в течение 2 секунд после обнаружения.

### Ключевые возможности

- **Мониторинг в реальном времени**: Непрерывный мониторинг до 500+ Telegram-источников с адаптивным polling постов и веток комментариев
- **AI-классификация**: Интеграция с OpenRouter с локальным эвристическим fallback для фильтрации и категоризации сообщений
- **Автоматическая геолокация**: Мультипровайдерное геокодирование (Яндекс, Nominatim) с интеллектуальным извлечением локации из контента
- **Кластеризация событий**: Автоматическая группировка связанных сообщений по времени и близости
- **Интерактивный дашборд**: Карта в реальном времени, лента событий и управление источниками
- **Webhook-интеграция**: Мгновенная доставка событий во внешние системы
- **Человек в цикле**: Встроенная очередь ревью для событий, требующих ручной верификации локации

## Архитектура

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  Telegram API   │────▶│  Backend Service │────▶│  Frontend UI    │
│  (Telethon)     │     │  (FastAPI)       │     │  (React + Vite) │
└─────────────────┘     └──────────────────┘     └─────────────────┘
                               │
        ┌──────────────────────┼──────────────────────┐
        ▼                      ▼                      ▼
┌─────────────────┐   ┌──────────────────┐   ┌─────────────────┐
│  OpenRouter AI  │   │  Geocoding API   │   │  SQLite Storage │
│  Классификация  │   │  (Яндекс/Nominatim)│   │  + WebSocket    │
└─────────────────┘   └──────────────────┘   └─────────────────┘
```

### Пайплайн обработки

1. **Сбор сообщений**: Новые сообщения из отслеживаемых Telegram-источников
2. **Фильтр по ключевым словам**: Быстрый начальный фильтр кандидатных сообщений
3. **AI-классификация**: Структурированный анализ через OpenRouter LLM
4. **Извлечение локации**: Комбинация географии источника с контекстом сообщения
5. **Геокодирование**: Конвертация текста локации в координаты
6. **Создание события**: Сохранение и рассылка обнаруженных инцидентов
7. **Доставка в реальном времени**: Push через WebSocket и webhook

## Быстрый старт

### Предварительные требования

- Docker и Docker Compose
- Учётные данные Telegram API (опционально, для реальных данных)
- API-ключ OpenRouter (опционально, для продакшен AI-классификации)

### Запуск через Docker

```bash
# Клонирование репозитория
git clone https://github.com/LernerF/OsintPlatform_project.git
cd OsintPlatform_project

# Создание файла окружения
cp .env.example .env

# Запуск сервисов
docker compose up --build

# Доступ к приложению
# Фронтенд: http://localhost:5173
# API бэкенда: http://localhost:8000/api
# Проверка здоровья: http://localhost:8000/api/health
```

### Локальная разработка

**Бэкенд:**
```bash
cd backend
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

**Фронтенд:**
```bash
cd frontend
npm install
npm run dev
```

## Функции в деталях

### Управление источниками

- Добавление источников из авторизованных диалогов Telegram
- Массовый импорт из текстовых файлов (до 500 каналов)
- Группировка источников по городу/региону
- Включение/отключение мониторинга для каждого источника или группы

### Обнаружение событий

- Настраиваемые фильтры по ключевым словам
- Мультикатегорийная классификация инцидентов
- Оценка уверенности и уровни риска
- Уровни точности локации (город, район, улица, адрес, ориентир)

### Геолокация

- Автоматическое извлечение локации из текста сообщения
- Fallback на географию источника при неясной локации
- Очередь ручного ревью для неоднозначных локаций
- Кэширование повторяющихся запросов геокодирования

### Обновления в реальном времени

- Стриминг событий через WebSocket
- Автоматическое обновление карты
- Мониторинг статуса источников
- Дашборд здоровья системы

## Справочник API

### REST-эндпоинты

```
GET  /api/health                    # Проверка здоровья
GET  /api/sources                    # Список всех источников
POST /api/sources                    # Создать источник
PATCH /api/sources/{id}              # Обновить источник
GET  /api/events                     # Список событий
GET  /api/events/{id}                # Детали события
GET  /api/clusters/active            # Активные кластеры событий
GET  /api/telegram/dialogs           # Доступные диалоги Telegram
POST /api/telegram/connect           # Подключить источник Telegram
POST /api/telegram/bulk-connect      # Массовое подключение из файла
GET  /api/system/status              # Статус здоровья системы
```

### WebSocket

```
WS /api/ws/events                   # Поток событий в реальном времени
```

Полная документация API: [api-reference.md](api-reference.md)

## Безопасность и этика

### Важные принципы

- Система предназначена **только для мониторинга гражданской безопасности**
- Все данные из **публично доступных** Telegram-источников
- События включают **оценки уверенности** и **уровни точности локации**
- Система **не** предоставляет военных рекомендаций или информации для целеуказания

### Обработка данных

- Исходные сообщения хранятся с полной атрибуцией
- Точность геолокации явно указана
- Ручное ревью для неопределённых локаций
- Автоматические действия требуют верификации для критических событий
